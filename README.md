# Vaishnavi Constructions

Business site for Vaishnavi Constructions, a row-house builder in Jalgaon. Built with Next.js, React, and Tailwind CSS.

## Pages

- Home — hero, planned layouts, project features, Jalgaon location, enquiry
- About Us
- Homes
- Project Gallery
- Buyers

The Enquire Now form asks for a call back. Submissions are saved locally in `data/enquiries.json` (gitignored). Phone and email in `src/data/site.ts` are blank until the office adds them.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```

## Notes

Home sizes and distances on the map are approximate planned figures, not a surveyed site plan. Photos in `public/images` are design images of the planned homes.
